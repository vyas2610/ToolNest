URL Encoder / Decoder

Safely encode non-ASCII characters and special query string symbols into percent-encoded strings, or decode encoded URLs back to readable text.

About ToolNest URL Encoder & Decoder

URLs are restricted to a specific subset of ASCII characters (RFC 3986). Any character outside this permitted range—including spaces, ampersands, quotation marks, and non-English characters—must be converted into a valid percent-encoded sequence (such as %20 for a space or %26 for an ampersand).

Component Mode vs. Full URL Mode

  • Component Encoding (encodeURIComponent): Encodes all characters with special syntactic meaning, including /, ?, &, and =. This is required whenever passing a URL or parameter value inside another query string parameter.
  • Full URL Encoding (encodeURI): Retains valid URI structural characters (like protocol delimiters and path slashes) while encoding only illegal characters like spaces.

Frequently Asked Questions

A malformed URI error occurs when a percent sign % is followed by characters that are not valid two-digit hexadecimal codes (0-9, A-F), or when an incomplete multi-byte UTF-8 sequence is encountered.
