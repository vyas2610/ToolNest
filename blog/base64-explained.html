What Is Base64 Encoding and How Does It Work?

Published September 2026 • 5 min read • Data Encoding

In computer science and web development, communication protocols such as SMTP (email) and HTTP were historically designed to transmit printable 7-bit ASCII text. When engineers needed to send binary assets (such as images, compiled files, or encryption keys) through channels expecting text, they turned to Base64.

How Base64 Works (The Math)

Base64 takes binary data and translates every 3 bytes (24 bits) into 4 printable characters chosen from a 64-symbol alphabet (A-Z, a-z, 0-9, +, /):

  1. Take 3 bytes of binary data (24 bits total).
  2. Split those 24 bits into 4 groups of 6 bits each ($2^6 = 64$ combinations).
  3. Map each 6-bit integer to its corresponding character in the Base64 alphabet.
  4. If the final chunk contains fewer than 3 bytes, pad the end with = characters.

Because every 3 bytes become 4 characters, Base64 increases payload size by approximately 33%.

Common Use Cases

  • Data URLs: Embedding small SVGs or icons directly into CSS stylesheets or HTML <img src="data:image/png;base64,..."> tags to eliminate additional HTTP requests.
  • Authentication Tokens: Encoding client credentials in HTTP Authorization: Basic ... headers.
  • Webhook Payloads: Transmitting binary signatures and cryptographic hashes safely in JSON structures.

Unicode & Emoji Safety
